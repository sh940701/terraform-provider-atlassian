# atlassian_jira_group_member (Resource)

Manages a single user's membership of a Jira Cloud group. Requires site administrator rights (POST/DELETE /rest/api/3/group/user).

## Example Usage

```terraform
resource "atlassian_jira_group" "reviewers" {
  name = "change-reviewers"
}

resource "atlassian_jira_group_member" "reviewer" {
  group_id   = atlassian_jira_group.reviewers.group_id
  account_id = "5b10ac8d82e05b22cc7d4ef5"
}
```
