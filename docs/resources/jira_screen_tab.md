# atlassian_jira_screen_tab (Resource)

Manages a tab on a Jira Cloud screen.

## Example Usage

```terraform
resource "atlassian_jira_screen_tab" "example" {
  screen_id = atlassian_jira_screen.example.id
  name      = "Example Tab"
}

# Jira gives every screen a default tab; position = 0 puts this tab (and its fields) ahead of it in the issue view.
resource "atlassian_jira_screen_tab" "first" {
  screen_id = atlassian_jira_screen.example.id
  name      = "기재사항"
  position  = 0
}
```

## Schema

### Required

- `name` (String) The name of the screen tab.
- `screen_id` (String) The ID of the screen this tab belongs to. Changing this forces recreation of the resource.

### Optional

- `position` (Number) Zero-based position of the tab among the screen's tabs. Jira's new issue view shows fields from all tabs in tab order, so `position = 0` puts this tab's fields first — ahead of the default tab Jira creates with every screen. Omit to leave the tab wherever Jira put it.

### Read-Only

- `id` (String) The ID of the screen tab.
